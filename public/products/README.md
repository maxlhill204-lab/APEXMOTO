# Product image folders

These production folders contain the owner-supplied APEX MOTO helmet, goggles, and helmet-bag images.

When adding another owned image:

1. Put it under a clear product folder in `public/products/`.
2. Use a descriptive lowercase filename.
3. Add its public path, real width, real height, and factual alt text to the product’s `images` array in `src/data/products.ts`.
4. Add `colour` when selecting that colour should switch the gallery image.
5. Check the crop on phone and desktop.

Do not add supplier or retailer imagery unless APEX MOTO has permission to use it.
